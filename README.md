# 공공기관 생성형 AI 업무혁신 — 2일 과정

공공기관 실무자 대상 교안·실습 데이터·이해 점검 퀴즈입니다.
이해 → 문서 → 데이터 분석 → 실행 순으로 난이도가 올라가고, **각 단계의 산출물이 다음 단계의 입력**이 됩니다.

- **이틀에 걸쳐 진행하고, 세션당 집합 3시간** · 사전학습은 집합 전 온라인 자습
- **교안 11종 · 실습 데이터 5벌 · 퀴즈 3종** — 결과물은 수업에서 직접 만듭니다
- 설계 원칙: 기능 교육이 아니라 **업무 흐름 설계**. 기초는 파일을 올리고, 중급은 폴더를 맡깁니다.

## 과정 안내 페이지

### 👉 https://keerhee.github.io/gh-genai-ax-2day/

교안 PDF, 실습 데이터, 퀴즈를 한 화면에서 내려받습니다.

세션 1과 세션 2 모두 **사전학습을 먼저 온라인으로 듣고** 집합 수업에 들어옵니다.

## 결과물은 수강생이 만듭니다

이 저장소에 있는 것은 **교안(프롬프트)과 입력 데이터**뿐입니다.
완성본 웹앱, 정답키, 미리 꾸며 둔 작업 폴더는 넣지 않았습니다.
보고서·지도·대시보드는 수업에서 직접 만들어 냅니다.

작업 폴더는 이렇게 만듭니다.

```
내작업폴더/
  CLAUDE.md     상시 규칙 — 폴더 루트에 둔다
  input/        이 저장소에서 복사 — 읽기 전용
  working/      직접 만든다 (계획 · 변경 로그 · 검토 기록)
  output/       직접 만든다 (보고서 · 지도 · 대시보드)
```

각 폴더의 `실습안내.md`에 입력 파일 목록과 주의할 점이 정리돼 있습니다.

## 파일 이름 규칙

- `교안.pdf` — 그 단계의 강의 자료. 프롬프트가 여기 들어 있습니다
- `input/` — 실습에 쓰는 원본. 깃허브에서 바로 표로 열어 볼 수 있습니다
- `CLAUDE.md` — 작업 폴더 루트에 두는 상시 규칙
- `실습안내.md` · `진행가이드.md` — 무엇을 어떤 순서로 만드는지
- `퀴즈.html` — 더블클릭하면 인터넷 없이 열립니다

교안은 PDF로만 둡니다. 원본 PPTX가 필요하면 담당자에게 요청하십시오.

## 실습 데이터

전부 **교육용 가상(합성) 자료**입니다. 실제 민원·실제 좌표는 쓰이지 않았습니다.
민원 파일에는 신고자 연락처와 생년이 들어 있습니다. 합성값이지만
**안전 정제 단계 전에는 지도·보고서·대시보드에 쓰지 않는 것**을 수업 규칙으로 삼습니다.

## 강사용 자료는 포함하지 않았습니다

정답키, 분류 정답표, 데이터 생성기, 캡스톤 모범답안 문서는 제외했습니다.
연습 과제는 **정답 수치를 공개하지 않는 것이 설계의 일부**입니다.

강사용 자료는 비공개 저장소 [gh-genai-ax-2day-instructor](https://github.com/keerhee/gh-genai-ax-2day-instructor) 에 따로 있습니다(권한이 있어야 열립니다).
