# 공공기관 생성형 AI 업무혁신 — 2일 과정

공공기관 실무자 대상 교안·실습 데이터·이해 점검 퀴즈입니다.
이해 → 문서 → 데이터 분석 → 실행 순으로 난이도가 올라가고, **각 단계의 산출물이 다음 단계의 입력**이 됩니다.

- **이틀에 걸쳐 진행하고, 세션당 집합 3시간** · 사전학습은 집합 전 온라인 자습
- **교안 11종 · 실습 데이터 5벌 · 퀴즈 3종 · 완성본 웹앱 3개**
- 설계 원칙: 기능 교육이 아니라 **업무 흐름 설계**. 기초는 파일을 올리고, 중급은 폴더를 맡깁니다.

## 과정 안내 페이지

### 👉 https://keerhee.github.io/gh-genai-ax-2day/

교안 PDF, 실습 데이터, 퀴즈, 완성본 웹앱을 한 화면에서 내려받습니다.

## 폴더

**폴더 번호가 곧 수강 순서입니다.** 각 폴더 안에 그 단계에 필요한 것이 전부 들어 있습니다.

| 폴더 | 단계 | 들어 있는 것 |
|---|---|---|
| `session1-1_사전학습I_원리` | 사전학습 I | 교안 |
| `session1-2_기초1_문서` | 기초 1 · 문서 | 교안 · 회의 메모 · 용어 브리프 |
| `session1-3_기초2_데이터분석` | 기초 2 · 데이터 분석 | 교안 · 실습 데이터 · 퀴즈 · 완성본 대시보드 |
| `session1-4_사전학습II_Agent·AX` | 사전학습 II | 교안 |
| `session2-1_중급_폴더위임` | 중급 | 교안 · 실습 폴더 · 퀴즈 · 완성본 대시보드 |
| `session2-2_연습과제` | 연습 과제 | 교안 · 실습 폴더 · 퀴즈 |
| `session2-3_캡스톤` | 캡스톤 | 교안 · 실습 폴더 · 완성본 지도 |

곁들이는 과정(본 트랙과 병행하지 않음)

| 폴더 | 내용 |
|---|---|
| `session1-5_엑셀에서클로드로` | 독립 과정 42장 · 참고자료 32장 · 축약본 14장 + 실습 데이터 |
| `session1-6_통합특강` | 사전학습 I+II를 한 번에 다루는 특강 32장 |

## 파일 이름 규칙

- `교안.pdf` — 그 단계의 강의 자료
- `실습데이터.zip` / `실습폴더.zip` — 압축을 풀어 **그 폴더째** 작업 폴더로 엽니다
- `퀴즈.html` · `완성본_*.html` — 더블클릭하면 인터넷 없이 열립니다

교안은 PDF로만 둡니다. 원본 PPTX가 필요하면 담당자에게 요청하십시오.

## 실습 데이터

전부 **교육용 가상(합성) 자료**입니다. 실제 민원·실제 좌표는 쓰이지 않았습니다.
민원 파일에는 신고자 연락처와 생년이 들어 있습니다. 합성값이지만
**안전 정제 단계 전에는 지도·보고서·대시보드에 쓰지 않는 것**을 수업 규칙으로 삼습니다.

## 강사용 자료는 포함하지 않았습니다

정답키, 분류 정답표, 데이터 생성기, 캡스톤 모범답안 문서는 제외했습니다.
연습 과제는 **정답 수치를 공개하지 않는 것이 설계의 일부**입니다.

강사용 자료는 비공개 저장소 [gh-genai-ax-2day-instructor](https://github.com/keerhee/gh-genai-ax-2day-instructor) 에 따로 있습니다(권한이 있어야 열립니다).
