# 공공기관 생성형 AI 업무혁신 — 2일 과정(12H)

공공기관 실무자 대상 **생성형 AI 업무혁신 과정**의 교안·실습 데이터·이해 점검 퀴즈입니다.
이해 → 문서 → 데이터 → 실행 순으로 난이도가 올라가고, **각 단계의 산출물이 다음 단계의 입력**이 됩니다.

- **집합 2일 × 6시간 = 12시간** + 사전학습 자습 2회(각 40분)
- **덱 11종 · 실습 데이터 5벌 · 퀴즈 3종 · 완성본 웹앱 3개**
- 설계 원칙: 기능 교육이 아니라 **업무 흐름 설계**. 기초는 파일을 올리고, 중급은 폴더를 맡깁니다.

## 과정 안내 페이지

### 👉 https://keerhee.github.io/gh-genai-ax-2day/

덱 PDF·PPTX, 실습 데이터 ZIP, 퀴즈, 완성본 웹앱을 한 화면에서 내려받습니다.

## 폴더 구성

```
공공기관 생성형 AI 과정/
  session1/   사전학습 I · 기초 1 · 기초 2 · 사전학습 II · 엑셀 · 통합 특강
  session2/   중급 · 연습 과제 · 캡스톤
index.html    과정 안내 페이지 (GitHub Pages 홈)
```

각 세션 폴더의 `00_수업순서_INDEX.md`에 수강 순서와 파일 매핑이 정리돼 있습니다.
실습 데이터는 폴더로도, ZIP으로도 들어 있습니다. ZIP은 **폴더째 작업 폴더로 열어 쓰는 용도**입니다.

## 실습 데이터

전부 **교육용 가상(합성) 자료**입니다. 실제 민원·실제 좌표는 쓰이지 않았습니다.

| 벌 | 쓰는 곳 | 규모 |
|---|---|---|
| 민원 접수 대장 | 기초 2 · 엑셀 과정 | 794행 |
| 무단투기 민원 폴더 | 중급 | 212행 + CCTV 30 + 행정동 7 |
| 새올구 연습 폴더 | 연습 과제 | 212행 + CCTV 30 + 행정동 7 |
| 어린이 보행안전 | 캡스톤 | 보호구역 32 · CCTV 139 · 사고 24 |
| 기초 1 첨부 | 기초 1 | 회의 메모 · 용어 브리프 |

민원 파일에는 신고자 연락처와 생년이 들어 있습니다. 합성값이지만
**안전 정제 단계 전에는 지도·보고서·대시보드에 쓰지 않는 것**을 수업 규칙으로 삼습니다.

## 강사용 자료는 포함하지 않았습니다

정답키, 분류 정답표, 데이터 생성기, 캡스톤 모범답안 문서는 제외했습니다.
연습 과제는 **정답 수치를 공개하지 않는 것이 설계의 일부**입니다.

- 완성본 웹앱 3개 — 민원 대시보드 · 운영 대시보드 · 미대응 지도
