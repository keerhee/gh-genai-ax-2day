# 캡스톤 — 실습 입력 (Track B 스냅샷)

인터넷이 되면 Track A로 공개데이터를 직접 구합니다.
내부망이거나 시간이 짧으면 아래 스냅샷을 씁니다. 프롬프트는 그대로 두고 파일만 바꿉니다.

## 작업 폴더는 직접 만듭니다

이 폴더에 있는 것이 **입력 전부**입니다. 작업 폴더는 학습자가 만듭니다.

1. 빈 폴더를 하나 만듭니다.
2. `CLAUDE.md`를 그 폴더 **루트**에 넣습니다. Claude Code가 매 명령마다 읽습니다.
3. `input/`을 통째로 복사합니다. **input 안의 파일은 수정하지 않습니다.**
4. `working/`과 `output/` 빈 폴더를 만듭니다.

```
내작업폴더/
  CLAUDE.md     상시 규칙
  input/        원본 — 읽기 전용
  working/      판단의 흔적 (계획 · 변경 로그 · 검토 기록)
  output/       산출물 (보고서 · 지도 · 대시보드)
```

## input 파일

| 파일 | 역할 | 규모 |
|---|---|---|
| `child_safety_zones.csv` | 수요지점 — 어린이보호구역 | 32행 × 12열 |
| `cctv.csv` | 시설(공급) — CCTV 설치목적·화소·좌표 | 139행 × 14열 |
| `population_by_dong.csv` | 가중치 — 행정동 인구·0~12세 | 7행 × 9열 |
| `pedestrian_accidents.csv` | 사건 신호 — 어린이 보행사고 | 24행 × 9열 |
| `project_conditions.txt` | 예산 5천만원 · 단가 8종 · 제약 6개 | 텍스트 |

파일마다 좌표 컬럼 이름이 다릅니다. 컬럼명을 가정하지 말고 헤더부터 읽습니다.
진행 순서와 채점 기준은 `진행가이드.md`에 있습니다.

## 이 폴더에 없는 것

완성본 웹앱과 정답키는 들어 있지 않습니다.
**교안의 프롬프트로 직접 만드는 것이 과제입니다.**

데이터는 전부 교육용 가상(합성) 자료입니다.
