# 설치 안내 — Claude Desktop · VS Code · Claude Code

공공기관 생성형 AI 업무혁신 · 보충교재 · 윈도우/맥 공통
2026년 9월 기준입니다. 화면과 메뉴 이름은 버전에 따라 조금씩 달라질 수 있습니다.

## 0. 먼저 읽을 것 — 셋 중 하나만 고르면 됩니다

세 가지를 다 깔 필요가 없습니다. **무엇을 하려는지**에 따라 하나만 고르십시오.

| 하려는 일                          | 설치할 것                          | 터미널      | 이 문서의 장    |
|------------------------------------|------------------------------------|-------------|-----------------|
| 대화 · 문서 작성 · 자료 정리 | **Claude Desktop** | 필요 없음 | 2장 |
| 폴더를 통째로 맡기는 실습 (중급 이상) | Claude Desktop **또는** VS Code + 확장 | 필요 없음 | 2장 또는 3장 |
| 명령창에서 `claude` 명령을 직접 쓰기 | Claude Code CLI | 필요함 | 4장 |

**대부분의 수강생은 2장(Claude Desktop) 하나로 끝납니다.** Claude Desktop 안에 Claude Code가 이미 들어 있어서 Node.js도, 명령창도 필요 없습니다.

3장과 4장은 평소 코드 편집기를 쓰는 분, 또는 명령창 작업이 익숙한 분을 위한 선택지입니다.

## 1. 설치 전에 확인할 것

### 1.1 요금제 — 가장 먼저 확인하십시오

**Claude Code는 유료 요금제에서만 동작합니다.** Pro · Max · Team · Enterprise 중 하나이거나, Claude Console 계정이어야 합니다. **무료 요금제에는 Claude Code가 포함되지 않습니다.**

- Claude Desktop 앱 자체는 무료 계정으로도 설치되고, **Chat 탭**은 쓸 수 있습니다.
- 다만 파일을 다루는 **Code 탭**을 누르면 요금제 안내가 뜹니다.
- VS Code 확장도 같습니다. 유료 구독 또는 Console 계정이면 되고, API 키는 따로 필요하지 않습니다.
- 기관 단위로 도입한다면 Team 요금제를 부서 계정으로 묶는 방식을 먼저 확인하십시오.

실습은 Code 탭 또는 VS Code 확장을 씁니다. 수업 전에 요금제를 정리해 두십시오.

### 1.2 컴퓨터 사양

| 항목            | 최소 조건                                                      |
|-----------------|----------------------------------------------------------------|
| 윈도우 | Windows 10 버전 1809 이상 (또는 Windows Server 2019 이상) |
| 맥 | macOS 13.0 이상 |
| 메모리 | 4 GB 이상 |
| 프로세서 | x64 또는 ARM64 |
| 네트워크 | 인터넷 연결 필수 |

맥은 인텔·애플실리콘 모두 같은 설치 파일 하나를 씁니다. 윈도우는 x64와 ARM64의 설치 파일이 다릅니다.

### 1.3 기관 네트워크 — 막히면 대개 여기입니다

내부망 방화벽이 외부 접속을 막고 있으면 로그인 단계에서 멈춥니다. 설치가 계속 실패하면 아래 주소를 정리해 정보화 담당 부서에 허용을 요청하십시오.

| 주소                         | 쓰이는 곳                                            |
|------------------------------|------------------------------------------------------|
| `api.anthropic.com` | 모든 대화 요청 |
| `claude.ai` | 계정 인증 |
| `claude.com` | 로그인 화면 · 내려받기 페이지 |
| `platform.claude.com` | 토큰 발급·갱신 (Console 계정 인증) |
| `downloads.claude.ai` | 설치 파일 내려받기 · 자동 업데이트 |
| `registry.npmjs.org` | npm으로 설치할 때만 |

Claude Desktop 앱과 브라우저판 claude.ai는 화면을 그리는 파일을 `assets-proxy.anthropic.com`과 `*.claudeusercontent.com`에서도 받아 옵니다. **`claude.ai`만 열어 주고 이 주소들을 막으면 오류 메시지 없이 빈 화면이 뜹니다.** 요청할 때 함께 적으십시오.

프록시를 쓰는 환경이라면 주소와 포트를 확인해 두십시오. 터미널로 설치했다면 아래처럼 지정합니다.

```bash
export HTTPS_PROXY=http://proxy.example.com:8080
export NO_PROXY="localhost,127.0.0.1,.example.go.kr"
```

기관이 자체 인증서로 통신을 검사하는 환경이라면, 그 루트 인증서 경로를 함께 지정합니다.

```bash
export NODE_EXTRA_CA_CERTS=/path/to/기관-루트인증서.pem
```

설치 파일(.exe/.dmg) 실행 자체가 보안 정책으로 차단되는 기관도 있습니다. 이건 네트워크가 아니라 단말 정책이므로 별도로 예외를 요청해야 합니다.

### 1.4 자료 반입 규칙 (본 과정 공통)

설치가 끝나도 **실제 민원 자료·개인정보는 입력하지 않습니다.** 교육에 쓰는 데이터는 전부 가상 자료입니다. 업무에 적용할 때는 기관의 정보보호 지침을 먼저 확인하십시오.

## 2. 길 A — Claude Desktop (권장)

터미널 없이 화면만으로 쓰는 방법입니다. **Claude Code가 앱 안에 함께 들어 있어 따로 설치할 것이 없습니다.**

내려받는 곳은 윈도우·맥 모두 같습니다.

```text
https://claude.com/download
```

예전 주소 `claude.ai/download`로 들어가도 이 주소로 넘어갑니다.

### 2.1 윈도우

1. 브라우저에서 **<https://claude.com/download>** 로 들어갑니다.
2. Windows용 설치 파일(`.exe`)을 내려받습니다.
   - 일반적인 PC는 **x64**를 받습니다.
   - Surface 등 ARM 계열이면 **ARM64**를 받습니다. 어느 쪽인지 모르면 `설정 → 시스템 → 정보`의 "시스템 종류"를 보십시오.
3. 내려받은 파일을 두 번 눌러 실행합니다. **관리자 권한은 필요 없습니다.**
4. 설치가 끝나면 **시작 메뉴**에서 Claude를 실행합니다.

### 2.2 맥

1. 브라우저에서 **<https://claude.com/download>** 로 들어갑니다.
2. macOS용 `.dmg` 파일을 내려받습니다. 인텔·애플실리콘 공용입니다.
3. `.dmg`를 두 번 눌러 열고, **Claude 아이콘을 Applications 폴더로 끌어다 놓습니다.**
4. **응용 프로그램** 폴더에서 Claude를 실행합니다.
5. "확인되지 않은 개발자" 경고가 뜨면 `시스템 설정 → 개인정보 보호 및 보안`에서 **열기**를 누릅니다.

### 2.3 첫 실행

1. 앱이 열리면 **로그인**합니다. 브라우저가 열리고, 거기서 승인하면 앱으로 돌아옵니다.
2. 화면 위쪽 가운데에 탭 세 개가 보입니다.

   | 탭       | 하는 일                                                        |
   |----------|----------------------------------------------------------------|
   | **Chat** | 일반 대화. 내 파일은 못 봅니다. claude.ai와 같습니다 |
   | **Cowork** | 격리된 가상 환경에서 혼자 오래 도는 작업 |
   | **Code** | **실습에서 쓰는 탭.** 내 컴퓨터의 파일을 직접 읽고 고칩니다 |

3. **Code** 탭을 누릅니다. 요금제 안내가 뜨면 1.1을 다시 보십시오.
4. **Local**을 고르고 **Select folder**로 작업 폴더를 지정합니다.
   중급 실습이라면 `CLAUDE.md`와 `input/`이 들어 있는 폴더를 고르면 됩니다.
   (Local 외에 Cloud · SSH · WSL도 고를 수 있지만 본 과정에서는 쓰지 않습니다.)
5. 보내기 단추 옆에서 모델과 **권한 모드**를 고릅니다.

### 2.4 권한 모드 — 처음에는 Manual

권한 모드는 Claude가 어디까지 스스로 하게 둘지를 정합니다. **유료 요금제의 기본값은 Auto이므로, 수업 첫날에는 직접 Manual로 바꾸십시오.**

| 모드             | 무엇이 달라지나                                                  |
|------------------|------------------------------------------------------------------|
| **Manual** | 파일을 고치기 전에 매번 묻습니다. **교육에서 쓰는 모드** |
| Auto | 위험한 동작만 걸러 내고 나머지는 묻지 않습니다 (기본값) |
| Accept edits | 파일 수정을 묻지 않고 바로 적용합니다 |
| Plan | 무엇을 할지 계획만 내놓고 파일은 건드리지 않습니다 |

Manual에서는 바뀔 내용을 좌우 비교 화면으로 보여 주고, **Accept / Reject**로 승인합니다. 무엇이 바뀌는지 눈으로 확인하는 습관이 먼저입니다.

## 3. 길 B — VS Code + Claude Code 확장

코드 편집기를 함께 쓰고 싶을 때 고릅니다. 이 방법도 **터미널이 필요 없습니다.** 확장이 필요한 실행 파일을 자체적으로 품고 있습니다.

### 3.1 VS Code 설치 — 윈도우

1. **<https://code.visualstudio.com/download>** 에서 Windows용 설치 파일을 내려받습니다.
2. **User Installer**를 고릅니다. 관리자 권한이 필요 없고 업데이트가 매끄럽습니다.
   (System Installer는 전 직원 공용 PC처럼 모든 계정에 설치할 때만 쓰며 관리자 권한이 필요합니다.)
3. `.exe`를 실행하고 안내대로 진행합니다. 설치 경로는 기본값을 그대로 둡니다.
4. 설치 과정에서 PATH 등록은 자동으로 됩니다.

### 3.2 VS Code 설치 — 맥

1. **<https://code.visualstudio.com/download>** 에서 macOS용 `.dmg`를 내려받습니다.
2. `.dmg`를 열고 **Visual Studio Code를 Applications 폴더로 끌어다 놓습니다.**
3. 응용 프로그램에서 실행합니다.
4. Dock에 고정하려면 Dock 아이콘을 **Control-클릭 → 옵션 → Dock에 유지**를 누릅니다.

### 3.3 Claude Code 확장 설치 (윈도우·맥 공통)

> VS Code 1.94.0 이상이어야 합니다. 오래된 버전이면 `도움말 → 업데이트 확인`으로 먼저 올리십시오.

1. VS Code를 엽니다.
2. 확장 화면을 엽니다.
   - 윈도우: `Ctrl` + `Shift` + `X`
   - 맥: `Cmd` + `Shift` + `X`
3. 검색창에 **`Claude Code`** 를 입력합니다.
4. 제작자가 **Anthropic**인 항목의 **Install**을 누릅니다. 확장 식별자는 아래와 같습니다.

```text
anthropic.claude-code
```

5. 설치 후 확장이 보이지 않으면 VS Code를 다시 시작합니다. 그래도 없으면 명령 팔레트에서 **Developer: Reload Window**를 실행합니다.

Cursor 등 VS Code 계열 편집기에도 같은 방법으로 설치됩니다. 마켓플레이스가 막힌 환경이라면 Open VSX(<https://open-vsx.org/extension/Anthropic/claude-code>)에서 받습니다.

### 3.4 명령으로 설치하기 (선택)

여러 대에 같은 환경을 깔아야 하거나 화면에서 찾기가 번거로우면, 명령 한 줄로도 설치됩니다. 이때 쓰는 것은 `claude`가 아니라 **VS Code가 제공하는 `code` 명령**입니다.

**먼저 `code` 명령이 되는지 확인합니다.**

```bash
code --version
```

버전 번호가 세 줄 나오면 준비된 것입니다. `command not found` 또는 `'code'은(는) 내부 또는 외부 명령이 아닙니다`가 나오면 아래를 먼저 하십시오.

- **윈도우:** User Installer로 설치했다면 자동 등록됩니다. 방금 설치했다면 **명령창을 닫았다 다시 여십시오.**
- **맥:** 한 번 등록해 주어야 합니다. VS Code에서 `Cmd+Shift+P`를 누르고 **`Shell Command: Install 'code' command in PATH`** 를 실행합니다.

**확장을 설치합니다.**

```bash
code --install-extension anthropic.claude-code
```

**설치됐는지 확인합니다.**

```bash
code --list-extensions --show-versions
```

목록에 `anthropic.claude-code@…` 가 보이면 됩니다. 목록이 길면 뒤에 `| grep claude`(맥) 또는 `| findstr claude`(윈도우)를 붙여 걸러 보십시오.

지울 때는 `code --uninstall-extension anthropic.claude-code` 입니다.

### 3.5 첫 실행

1. 아무 파일이나 하나 열면 편집기 **오른쪽 위**에 별 모양(Spark) 아이콘이 생깁니다. 그것을 누릅니다.
   - 왼쪽 **활동 막대**의 같은 아이콘을 눌러도 됩니다. 이쪽은 파일을 안 열어도 늘 보입니다.
   - 또는 명령 팔레트(`Ctrl+Shift+P` / `Cmd+Shift+P`)에서 `Claude Code`를 검색합니다.
2. 처음 열면 로그인 화면이 나옵니다. **Sign in**을 누르고 브라우저에서 승인합니다.
3. 프롬프트 상자 아래의 권한 모드를 **Manual**로 바꿉니다. 기본값은 Auto입니다.
4. `@`를 입력하면 파일을 지정해 넘길 수 있습니다. 예: `@input/complaints_200.csv`
   편집기에서 줄을 선택한 뒤 `Alt+K`(맥 `Option+K`)를 누르면 줄 번호까지 붙습니다.

### 3.6 VS Code 안에서 쓰는 명령

VS Code에서 치는 명령은 **치는 자리가 세 군데**입니다. 어디에 치는지를 먼저 구분하십시오.

| 치는 자리                        | 명령                            | 하는 일                                         |
|----------------------------------|---------------------------------|-------------------------------------------------|
| 명령 팔레트 `Ctrl/Cmd+Shift+P` | `Claude Code: Open in New Tab` | 새 탭에서 대화를 시작합니다 |
| 명령 팔레트 | `Claude Code: Open in Side Bar` | 사이드바에 붙여 둡니다 |
| 명령 팔레트 | `Claude Code: Open Walkthrough` | 기본 사용법을 훑어 줍니다 |
| 명령 팔레트 | `Developer: Reload Window` | 아이콘이 안 보이거나 로그인이 풀렸을 때 |
| 프롬프트 상자 | `/` | 명령 메뉴 (모델 전환 · 파일 첨부 · 설정) |
| 프롬프트 상자 | `/login` | 로그인이 풀렸을 때 다시 로그인 |
| 통합 터미널 ``Ctrl/Cmd+` `` | `claude` | CLI 실행 — **4장 설치가 따로 필요합니다** |

**여기서 가장 많이 헷갈리는 것 하나.** 확장은 대화창용 실행 파일을 자체적으로 품고 있지만, **`claude` 명령을 PATH에 넣어 주지는 않습니다.** 그래서 확장만 깔고 통합 터미널에서 `claude`를 치면 "명령을 찾을 수 없다"가 납니다. 정상입니다 — 통합 터미널에서 `claude`를 쓰려면 4장의 CLI를 따로 설치하십시오.

반대로 CLI만 있고 확장이 없는 상태에서 VS Code 통합 터미널에 `claude`를 치면, 확장이 자동으로 설치됩니다.

외부 터미널에서 띄운 Claude Code를 VS Code와 연결하려면, 그 안에서 `/ide`를 실행합니다.

## 4. 길 C — 터미널에서 `claude` 쓰기 (선택)

명령창에서 직접 쓰고 싶을 때만 하십시오. **2장이나 3장으로 실습하는 데는 필요 없습니다.**

### 4.1 윈도우

관리자 권한으로 열 필요는 없습니다. 먼저 **어느 창인지** 확인하십시오 — 프롬프트가 `PS C:\`로 시작하면 PowerShell, `C:\`로만 시작하면 CMD입니다.

**PowerShell에서:**

```powershell
irm https://claude.ai/install.ps1 | iex
```

**명령 프롬프트(CMD)에서:**

```bat
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
```

**winget을 쓰는 기관이라면** 이 한 줄로도 됩니다. 다만 이 방식은 자동 갱신이 되지 않아 가끔 `winget upgrade Anthropic.ClaudeCode`로 직접 올려야 합니다.

```powershell
winget install Anthropic.ClaudeCode
```

> `'irm' is not recognized...` 오류가 나면 CMD에 PowerShell 명령을 넣은 것입니다.
> `The token '&&' is not a valid statement separator` 오류가 나면 반대입니다.

설치가 끝나면 창을 닫았다 다시 엽니다.

**Git for Windows (선택).** <https://git-scm.com/downloads/win> 에서 설치하면 Claude Code가 Bash 명령을 쓸 수 있습니다. 없어도 동작하며, 이 경우 PowerShell로 명령을 실행합니다.

### 4.2 맥

**터미널**(응용 프로그램 → 유틸리티 → 터미널)을 열고 붙여 넣습니다.

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Homebrew를 쓴다면 이쪽도 됩니다. 다만 이 방식은 자동 갱신이 되지 않아 가끔 `brew upgrade claude-code`로 직접 올려야 합니다.

```bash
brew install --cask claude-code
```

### 4.3 npm으로 설치 (선택)

이미 Node.js를 쓰고 있다면 이 방법도 있습니다. **Node.js 22 이상**이 필요합니다.

```bash
npm install -g @anthropic-ai/claude-code
```

`sudo npm install -g`는 쓰지 마십시오. 권한 문제를 만듭니다.

### 4.4 설치 확인

```bash
claude --version
```

`2.1.211 (Claude Code)` 처럼 버전이 찍히면 성공입니다.

더 자세히 보려면 아래를 실행합니다. 설치 상태와 설정 오류를 한 번에 점검해 줍니다.

```bash
claude doctor
```

### 4.5 실행

작업할 폴더로 이동한 뒤 실행합니다.

```bash
claude
```

처음 실행하면 브라우저가 열리고, 로그인하면 대화가 시작됩니다.

### 4.6 업데이트

기본 설치 방식은 뒤에서 알아서 최신으로 올라갑니다. 지금 바로 올리려면 아래를 실행합니다.

```bash
claude update
```

winget·Homebrew·npm으로 설치했다면 각 도구의 업그레이드 명령을 써야 합니다.

## 6. 막혔을 때

| 증상                                   | 확인할 것                                                  |
|----------------------------------------|------------------------------------------------------------|
| Code 탭을 누르면 업그레이드 안내가 뜬다 | 무료 요금제입니다. 1.1 참고 |
| 로그인 창이 열리다 멈춘다 | 기관 방화벽·프록시. 1.3의 주소 표를 들고 정보화 부서에 문의 |
| 화면이 오류도 없이 하얗게 비어 있다 | `claudeusercontent.com` 계열이 막힌 경우입니다. 1.3 참고 |
| 맥에서 "확인되지 않은 개발자" | `시스템 설정 → 개인정보 보호 및 보안`에서 **열기** |
| 윈도우에서 설치 파일이 차단된다 | 기관 단말 보안 정책. 정보화 부서에 예외 요청 |
| 확장을 깔았는데 아이콘이 없다 | VS Code를 다시 시작. 그래도 없으면 버전이 1.94.0 미만인지 확인 |
| 확장에서 계속 로그인하라고 나온다 | 명령 팔레트에서 **Developer: Reload Window** 실행 |
| 확장은 깔렸는데 터미널에서 `claude`가 안 된다 | 정상입니다. 확장은 `claude`를 PATH에 넣지 않습니다. 3.6 참고 |
| 맥에서 `code` 명령이 없다 | `Cmd+Shift+P` → `Shell Command: Install 'code' command in PATH` |
| `claude`가 명령을 못 찾는다 | 명령창을 닫았다가 다시 여십시오. 그래도 안 되면 `claude doctor` |
| 한글 폴더 이름에서 오류가 난다 | 경로가 아주 길면 문제가 생깁니다. 바탕화면 등 짧은 경로로 옮겨 보십시오 |

오류 메시지로 원인을 바로 가릴 수 있는 경우도 있습니다.

| 메시지                                            | 뜻                                     |
|---------------------------------------------------|----------------------------------------|
| `'irm' is not recognized as an internal or external command` | CMD에 PowerShell 명령을 넣었습니다 |
| `The token '&&' is not a valid statement separator` | PowerShell에 CMD 명령을 넣었습니다 |
| `command not found: claude` | 창을 닫았다 다시 여십시오 |
| `Not logged in · Please run /login` | 확장에서 로그인이 풀렸습니다. Reload Window |

혼자 해결되지 않으면 **오류 메시지를 그대로 찍은 화면**을 가지고 문의하십시오. 메시지 문구가 원인을 가장 빨리 알려 줍니다.

## 7. 설치한 다음 — 공공기관에서 지킬 것

1. **원본은 건드리지 않습니다.** `input/` 아래 파일은 읽기 전용으로 두고, 결과는 `output/`에 새로 만듭니다.
2. **개인정보는 넣지 않습니다.** 연락처·생년·상세주소는 분석 데이터에서 빼고 시작합니다.
3. **처음에는 Manual 모드로 씁니다.** 무엇이 바뀌는지 확인하고 승인하는 습관이 먼저입니다.
4. **AI가 만든 결과는 초안입니다.** 숫자·사실·출처는 사람이 다시 확인해야 결재선에 올릴 수 있습니다.
