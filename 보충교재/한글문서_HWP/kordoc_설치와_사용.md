# 한글 문서(HWP·HWPX)를 클로드로 다루기 — kordoc

한컴오피스 없이 한글 문서를 **읽고 · 만들고 · 채우는** 오픈소스 도구입니다.
`.hwp`·`.hwpx`를 마크다운으로 바꾸고, 반대로 마크다운을 공문서 HWPX로 만듭니다.

- 저장소 <https://github.com/chrisryugj/kordoc> · MIT 라이선스
- npm 패키지 `kordoc` (이 문서 작성 시점 4.13.1)
- **필요한 것 — Node.js 18 이상.** 한컴오피스는 필요 없습니다.

> 이 문서의 명령은 전부 이 폴더의 `예제/` 파일로 실제 실행해 확인한 것입니다.

---

## 1. 설치

세 가지 방법이 있습니다. **하나만** 고르면 됩니다.

### 방법 A — 클로드 코드 플러그인 (가장 간단)

클로드 코드 대화창에 그대로 칩니다.

```
/plugin marketplace add chrisryugj/kordoc
/plugin install kordoc@kordoc
```

`.hwp`·`.hwpx`를 언급하거나 문서를 만들어 달라고 하면 자동으로 붙습니다.

### 방법 B — Claude Desktop에 MCP로 붙이기

```bash
npx -y kordoc setup
```

설치 마법사가 쓰는 AI 도구를 찾아 설정 파일을 알아서 고쳐 줍니다.
직접 고치려면 `~/Library/Application Support/Claude/claude_desktop_config.json`
(윈도우는 `%APPDATA%\Claude\claude_desktop_config.json`)에 이렇게 넣습니다.

```json
{
  "mcpServers": {
    "kordoc": {
      "command": "npx",
      "args": ["-y", "kordoc", "mcp"]
    }
  }
}
```

윈도우는 `"command": "cmd"`, `"args": ["/c", "npx", "-y", "kordoc", "mcp"]`로 씁니다.

### 방법 C — 터미널에서 명령으로만

설치 없이 그때그때 실행합니다.

```bash
npx -y kordoc 문서.hwpx
```

자주 쓰면 한 번 설치해 둡니다.

```bash
npm install -g kordoc
```

## 2. 읽기 — 한글 문서를 마크다운으로

```bash
npx kordoc "예제/1_업무보고 양식.hwpx"          # 화면에 출력
npx kordoc 문서.hwp -o 문서.md                      # 파일로 저장
npx kordoc *.pdf -d ./결과/                         # 여러 개 한꺼번에
```

실제 출력(앞부분)입니다.

```
제목 HY헤드라인M 20~25

❍ 업무보고 개요 (휴먼명조 15, 장평 100)

ʼ26. 7. 7.(목) 00000과(00000팀장 홍길순 ☎ 3890)

□ 작은 제목(HY헤드라인M 16)

 ㅇ 내 용 : 휴먼명조 15, 장평 100
```

**읽어 들이는 형식** — HWPX · HWP 5.x · HWP 3.x · HWPML · PDF · XLSX · XLS ·
DOCX · PNG/JPG/WebP(이미지는 OCR 자동)

자주 쓰는 선택지

| 옵션 | 하는 일 |
|---|---|
| `--format json` | 블록·쪽·메타데이터가 든 JSON |
| `--format chunks` | RAG용 구조 청크 |
| `-p 1-3` | 특정 쪽만 |
| `--ocr` | 스캔 PDF 글자 인식(첫 사용 시 모델 약 18MB 받음) |
| `--password 암호` | 암호 걸린 문서 |

### PDF도 같은 방법으로

한글 문서만이 아니라 PDF도 마크다운이 됩니다. 스캔본이 아니면 옵션 없이 됩니다.

```bash
npx kordoc "예제/서울시_공무원_생성형_AI_활용_교육_계획서_gemini.pdf" -o 계획서.md
```

4쪽짜리 계획서가 205줄 마크다운이 되고, **제목 위계가 살아납니다.**

```
# 1. 교육 개요 및 추진 배경
# 3. 상세 커리큘럼 및 일자별 주요 내용
### [모듈 1] AI 리터러시와 서울시 행정의 미래 (오전 09:00 ~ 10:30)
### [모듈 2] 성과를 창출하는 프롬프트 디자인 기술 (오전 10:30 ~ 12:00)
```

검색·질의용으로 쪼개려면 `chunks`를 씁니다. 청크마다 **어느 제목 아래 몇 쪽인지**가
같이 붙어 나오므로, 나중에 근거를 되짚을 수 있습니다.

```bash
npx kordoc 계획서.pdf --format chunks -o 청크.json
# → 청크 24개 · 각 청크에 id · type · breadcrumb · text · page
```

스캔해서 만든 PDF(글자가 이미지인 것)는 `--ocr`을 붙입니다.

```bash
npx kordoc 스캔본.pdf --ocr -o 결과.md
```

## 3. 쓰기 — 마크다운을 공문서 HWPX로

**이 기능이 공공기관에서 가장 쓸모 있습니다.** 클로드에게 보고서를 마크다운으로
쓰게 한 뒤, 그대로 한글 문서로 바꿉니다.

```bash
npx kordoc generate 보고서.md -o 보고서.hwpx
```

만들면서 **공문서 표기법을 함께 검수**해 줍니다. 실제로 받은 경고입니다.

```
⚠ [COLON_SPACE] L5 "간 :" — 쌍점은 앞말에 붙이고 뒤는 한 칸 띄움 (예) 원장: 김갑동)
⚠ [TILDE_SPACE] L5 "~" — 물결표(∼) 앞뒤는 붙여 씀 (예) 2. 20.∼2. 24.)
```

행정업무운영 편람 기준입니다. 검수만 따로 돌릴 수도 있습니다.

```bash
npx kordoc lint 보고서.md
```

만든 파일이 한컴독스에서 열리는지 구조를 확인합니다.

```bash
npx kordoc validate 보고서.hwpx
# → ✓ 구조 검증 통과 (엔트리 6개)
```

## 4. 양식 채우기

기관 양식의 빈칸만 채우고 **서식은 그대로 둡니다.**

```bash
npx kordoc fill 신청서.hwpx -f '성명=홍길동,전화=010-1234-5678' -o 결과.hwpx
npx kordoc fill 신청서.hwpx -j 값.json -o 결과.hwpx
npx kordoc fill --list-templates          # 내장 서식 목록
```

`성명=` 부분은 **양식에 실제로 있는 항목 이름**과 맞아야 합니다. 안 맞으면
`⚠️ 매칭 실패: 성명`이라고 알려 주고 그 칸은 건너뜁니다. 먼저 `npx kordoc 양식.hwpx`로
읽어서 항목 이름을 확인하고 쓰는 것이 확실합니다.

## 5. 그 밖에

| 명령 | 하는 일 |
|---|---|
| `patch 원본.hwpx 편집.md -o 결과.hwpx` | 서식을 지킨 채 내용만 갈아 끼움 |
| `redact 문서.hwpx -o 마스킹본.hwpx` | 주민번호·전화·이메일·계좌 자동 마스킹 |
| `seal 문서.hwpx --image 도장.png --anchor "(인)"` | 도장 이미지 얹기 |
| `render 문서.hwpx -o 미리보기.svg` | 편집 없이 모양 확인 |
| `profile 참조.hwpx -o 서식.json` | 기관 표 서식을 뽑아 `generate`에 재사용 |

## 6. 이 폴더의 예제

`예제/`에 공공기관에서 흔히 쓰는 양식 세 개를 넣었습니다.
전부 이름·전화번호가 `홍길순`·`010-0000-0000` 같은 **가짜 값**입니다.

| 파일 | 쓰임 |
|---|---|
| `1_업무보고 양식.hwpx` | 개조식 업무보고. 읽기·채우기 연습용 |
| `2_보고서 양식.hwpx` | 표지형 보고서 |
| `3_보고서 양식.hwpx` | 보고일시·보고자가 머리에 붙는 형식 |
| `서울시_공무원_생성형_AI_활용_교육_계획서_gemini.pdf` | PDF → 마크다운 변환 연습 (4쪽) |

> **이 계획서는 생성형 AI가 만들어 낸 가상 문서입니다.** 어떤 기관에서도 수립·승인한 적이
> 없고 기관명·일정·인원은 전부 지어낸 값입니다. 변환 연습에만 쓰고, 실제 계획이나
> 근거로 인용하지 마십시오. 자세한 것은 `예제/읽어보세요.md`.

한 번 해 보기 — 양식을 읽어 구조를 보고, 같은 틀로 새 보고서를 만듭니다.

```bash
npx kordoc "예제/1_업무보고 양식.hwpx" -o 양식구조.md
# 양식구조.md를 보고 내용을 채운 뒤
npx kordoc generate 내보고서.md -o 내보고서.hwpx
npx kordoc validate 내보고서.hwpx
```

## 7. 주의할 것

- **원본을 덮어쓰지 않습니다.** `-o`로 새 파일 이름을 반드시 줍니다.
- **개인정보가 든 문서를 다룰 때는 `redact`를 먼저 돌립니다.** 마스킹 전 파일을
  대화창에 붙여넣지 않습니다.
- 변환 결과는 **사람이 눈으로 확인합니다.** 표가 복잡한 문서는 열·행이 밀릴 수
  있습니다. `render`로 모양을 먼저 보는 것이 안전합니다.
- 이 도구는 한컴오피스가 아닙니다. **한컴독스에서 최종본을 한 번 열어 확인**한 뒤
  결재에 올립니다.
