- **꼭 해볼 것 2** — "집단 기준"을 `행정동`으로 바꾸면 가온동 평균 12.2일이 드러납니다.

## 실습 순서

덱의 프롬프트를 그대로 복사해 붙여넣고, 파일명만 자기 부서 파일로 바꾸면 됩니다.

1. **B1 품질검사** → `01_complaints_raw.csv`
2. **B2 KPI · B3 원인** → 정제본 + `02_complaints_segments.csv`
3. **B4 예측** → `03_complaints_monthly.csv`
4. **B5 기관장 보고서** → 앞 단계 산출물 전부

## 심어 둔 함정 (강사용)

- 완전 중복 18건 · 민원ID만 다른 실질 중복 12건 · 처리일 < 접수일 9건 · 처리일수 이상값 7건
- 날짜 형식 4종 혼재 (`YYYY-MM-DD` / `YYYY/MM/DD` / `YYYY.MM.DD` / `YYYY년 MM월 DD일`)
- 가온동 평균 처리일수 12.2일 대 그 외 6.9일
- 쓰레기 민원 최근 4개월 68건, 직전 4개월 46건 (+47.8%)
- 만족도 응답률 약 62% — 부서별 비교 시 응답 수를 함께 봐야 함
- 접수채널별 재민원율 격차는 채널의 문제가 아니라 쓰레기 민원의 채널 쏠림(구성 효과)
- `민원인연락처` 컬럼 — 보고서·대시보드에 절대 노출 금지
