# 공공기관 생성형 AI 중급 — 실습 폴더

이 폴더를 통째로 Claude Code 작업 폴더로 엽니다.

```
CLAUDE.md                  프로젝트 상시 규칙 (Claude Code가 매번 자동으로 읽습니다)
input/                     원본 — 절대 수정하지 않습니다
  complaints_200.csv           무단투기 민원 원본 212행 × 16열 (중복·오류·개인정보 포함)
  cctv_existing_30.csv         기존 CCTV 30대 — 설치연도·화소·촬영방향·야간성능
  district_profile.csv         행정동 기초현황 — 인구·세대·상가·원룸비율·분리수거함
  project_conditions.txt       사업조건 — 예산 3천만원 · 단가 9종 · 제약 6개
working/             작업 기록이 쌓이는 곳 (PLAN.md, cleaning_log.md, red_team_review.md, final_audit.md)
output/              산출물이 저장되는 곳 (01~11)
answer_key_instructor.csv              강사용 — 오염 건수와 심어 둔 함정
classification_answer_instructor.csv   강사용 — 민원 200건의 분류 정답과 확신도
00_dataset_generator.py                데이터 재생성 스크립트 (seed 20260903, 결과 동일)
answer/ops_dashboard.html              완성본 웹앱 — 더블클릭하면 예시 데이터로 바로 실행됩니다
```

## 완성본 웹앱 먼저 보기

`answer/ops_dashboard.html`을 브라우저로 더블클릭하세요. A~L을 다 돌렸을 때 나오는 화면입니다.

- 상단 한 줄: "반복 발생 지점이 15곳, 그중 반경 200m 안에 CCTV가 없는 곳이 12곳입니다.
  건수 1위는 가온동(51건)이지만 인구 1만명당 1위는 마루동(27.6건)입니다"
- 지도: 큰 원이 반복지점, 빨간 테두리가 CCTV 공백, 주황이 "CCTV가 있는데도 민원이 많은 곳"
- **꼭 볼 것** — 가온로 12길 일대는 CCTV가 1대 있는데 그 1대가 2017년 이전 장비입니다.
  표의 권고가 "설치"가 아니라 "노후 장비 교체·방향 조정"으로 나옵니다.
- "공백 지점에서 초안 채우기"를 누르면 예산 3천만원 초안이 잡히고 제약 위반이 경고로 뜹니다.

## 시작 방법
작업 폴더에서 Claude Code를 실행한 뒤, 덱의 **Prompt A**를 그대로 붙여 넣습니다.
A부터 L까지 순서대로 진행하되, 매 단계에서 산출물을 확인하고 넘어갑니다.

## 주의
- 좌표는 실제 지번이 아닌 가상 좌표입니다.
- 신고자 연락처·생년은 교육용 합성 데이터입니다. 실제 개인정보가 아닙니다.
- 자기 부서 데이터로 바꿔 쓸 때는 컬럼명만 맞추면 프롬프트를 그대로 씁니다.
- 파일명은 압축 해제 시 한글이 깨지지 않도록 모두 영문으로 두었습니다.
