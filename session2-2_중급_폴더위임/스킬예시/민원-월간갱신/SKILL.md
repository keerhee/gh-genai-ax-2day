# 민원 월간 갱신

규칙은 이 폴더의 `CLAUDE.md`에 있다. 여기에 다시 쓰지 않는다.
원본 보존·마스킹·추정 표시·사람 승인 지점은 전부 그쪽을 따른다.

## 먼저 확인한다

아래가 하나라도 어긋나면 **파일을 만들지 말고 멈춘 뒤 사람에게 묻는다.**

| 확인 | 기대 |
|---|---|
| `input/complaints_200.csv` 존재 | 있어야 한다 |
| 컬럼 16개 | 민원ID · 접수일 · 접수채널 · 행정동 · 주소 · 위도 · 경도 · 반복지점 · 반복여부 · 민원내용 · 처리상태 · 처리일 · 처리기간 · 담당부서 · 신고자연락처 · 신고자생년 |
| `input/` 나머지 3개 | cctv_existing_30.csv · district_profile.csv · project_conditions.txt |
| `working/classification_rule.md` | 첫 회차에 사람이 확정한 분류체계. **없으면 멈춘다** |

행 수는 달마다 다르다. 세어서 적는다. 지난달 숫자를 그대로 쓰지 않는다.

## 절차

① **품질검사** → `output/01_데이터품질보고서.md`
   전체 행 수 · 완전 중복 · 민원ID만 다른 실질 중복 · 결측(컬럼별 건수와 비율) ·
   날짜 형식 종류 · 처리일 < 접수일 · 좌표 결측을 센다. 항목 · 건수 · 비율 · 조치 4열 표.

② **정제** → `output/02_정제민원.xlsx` + `working/cleaning_log.md`
   중복 제거 · 날짜 형식 통일 · 개인정보 마스킹. 원본은 열기만 한다.
   고친 행마다 행번호와 이유를 로그에 남긴다.

③ **자동분류** → `output/04_민원분류.xlsx`
   `working/classification_rule.md`의 규칙을 그대로 적용한다. 규칙을 임의로 바꾸지 않는다.
   각 행에 민원유형 · 분류근거 · 분류확신도(0~1)를 붙인다.
   **확신도 0.5 미만은 사람 재검토용으로 분리한다.**

④ **KPI** → `output/06_핵심KPI.xlsx`
   유형별·행정동별 건수, 인구 1만명당·세대 1천당 보정값, 처리기간 중앙값, 미처리 비율.
   분모를 반드시 밝힌다. 단순 건수 순위와 보정 순위를 나란히 놓는다.

⑤ **지도** → `output/07_민원지도.html`
   좌표가 있는 건만 찍고, 좌표 실패 건은 목록으로 따로 낸다.
   지도에 연락처·생년·상세주소를 넣지 않는다.

⑥ **반복지점과 CCTV 대조** → 비교표
   반경 100m 안에 3건 이상 모인 지점을 찾고, 각 지점 반경 200m 안의 CCTV 수를 센다.
   ㉠ 민원 많고 CCTV 없음 ㉡ CCTV 있는데도 민원 많음 ㉢ 민원 적고 CCTV 많음으로 나눈다.
   **설치를 해결책으로 단정하지 않는다.** 현장에서 확인할 것은 "현장 확인 필요"로 남긴다.

⑦ **보고서** → `output/09_기관장보고서.docx`
   A4 한 장. 모든 숫자를 원본에서 다시 계산해 적는다.
   문장 앞에 [사실] · [가설] · [제안]을 붙인다.

⑧ **PPT와 대시보드** → `output/10_간부보고.pptx` · `output/11_dashboard.html`
   보고서와 같은 숫자, 같은 메시지를 쓴다. 대시보드는 외부 라이브러리 없이 단일 HTML.

⑨ **최종 감사** → `output/final_audit.md`
   보고서·PPT·대시보드에 나온 모든 숫자를 원본에서 재계산해 대조한다.
   일치 건수 / 불일치 건수 · 개인정보 노출 여부 · 배포 가능 여부를 적는다.

⑩ **요약 보고**
   지난달 대비 바뀐 숫자와 배포 가능 여부를 표로 답한다.
   지난달 값은 `output/final_audit.md`의 이전 판에서 읽는다.

## 판정 기준 — 달마다 바뀌지 않는 숫자

이 값들이 없으면 매달 결과가 달라진다. 반드시 이대로 쓴다.

| 항목 | 기준 |
|---|---|
| 완전 중복 | 16개 컬럼이 모두 같다 |
| 실질 중복 | 민원ID 하나만 다르고 나머지 15개가 같다 |
| 처리기간 | 처리일 − 접수일. 음수면 오류로 표시하고 삭제하지 않는다 |
| 저확신 | 분류확신도 0.5 미만 |
| 반복지점 | 반경 100m 안 3건 이상 |
| CCTV 공백 | 반복지점 반경 200m 안에 CCTV 0대 |
| 표본 부족 | 30건 미만 집단은 순위에서 빼고 따로 표시 |

## 멈추는 곳

| 상황 | 할 일 |
|---|---|
| 컬럼 이름이 위와 다르다 | 아무 파일도 만들지 않고 멈춘다 |
| `classification_rule.md`가 없다 | 분류체계부터 사람이 확정해야 한다고 알린다 |
| 분류불가가 지난달보다 눈에 띄게 늘었다 | ③에서 멈추고 새 유형 후보를 제안만 한다. **확정은 사람이 한다** |
| 예산·정책 대안을 새로 짜야 한다 | 이 스킬 밖이다. 반경과 단가는 값을 바꾸면 결론이 뒤집히므로 사람이 쥔다 |
| 감사에서 불일치가 남았다 | 배포 가능으로 적지 않는다. 불일치 목록을 보여주고 멈춘다 |
