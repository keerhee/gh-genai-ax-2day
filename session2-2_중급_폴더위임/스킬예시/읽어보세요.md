# 이 폴더를 어디에 두나

`민원-월간갱신` 폴더를 **통째로** 아래에 복사합니다. 폴더 이름이 곧 스킬 이름입니다.

| 쓰는 도구 | 두는 곳 |
|---|---|
| Claude Code · Claude Desktop | 프로젝트 폴더 안 `.claude/skills/민원-월간갱신/SKILL.md` |
| 여러 부서에서 같은 절차를 쓸 때 | 개인 폴더 `~/.claude/skills/` (윈도우는 `C:/Users/<사용자>/.claude/skills/`) |
| claude.ai (웹) | 설정에서 코드 실행을 켠 뒤 `Customize → Skills`에 이 폴더를 ZIP으로 올립니다 |

## 함께 있어야 하는 것

SKILL.md는 **절차·판정 기준·멈출 곳**을 다 들고 있습니다. 하지만 **규칙과 데이터는
폴더가 들고 있습니다.** 이 파일만 다른 폴더에 복사하면 절차는 알아도 규칙을 모릅니다.

| 있어야 하는 것 | 없으면 |
|---|---|
| `CLAUDE.md` | 원본 보존 · 마스킹 · 추정 표시 규칙이 없다 |
| `input/` 파일 4개 | 셀 데이터가 없다 |
| `working/classification_rule.md` | 분류 단계에서 멈춘다. 첫 회차에 사람이 확정한다 |
| `output/final_audit.md` (이전 판) | 지난달 대비 비교를 못 한다. 첫 달은 없어도 된다 |

**규칙을 SKILL.md에 옮겨 적지 않은 것은 일부러입니다.** 두 곳에 같은 규칙이 있으면
한쪽만 고쳤을 때 어느 쪽이 맞는지 알 수 없습니다.

다른 부서로 가져갈 때는 **폴더 한 벌을 통째로** 가져갑니다. SKILL.md 한 장이 아니라
`CLAUDE.md` + `input/` + `.claude/skills/`가 한 세트입니다.

## 쓰는 법

**먼저 파일을 바꿔 넣습니다.** 탐색기에서 `input/complaints_200.csv`를 이번 달 자료로
덮어씁니다. **파일 이름은 그대로 둡니다.**

그 다음 새 대화창에서 한 줄만 칩니다.

```
이번 달 민원 갱신해줘
```

품질검사 → 정제 → 분류 → KPI → 지도 → CCTV 대조 → 보고서 → PPT·대시보드 → 감사가
순서대로 돌고, 마지막에 지난달 대비 바뀐 숫자와 배포 가능 여부를 표로 답합니다.

컬럼 이름이 다르면 **아무 파일도 만들지 않고 멈춥니다.**

## 알아둘 것

- **스킬 목록은 대화를 시작할 때 읽힙니다.** 지금 열려 있는 대화에서는 안 잡힙니다.
  새 대화를 열어야 통합니다.
- **이름을 외울 필요는 없습니다.** 이름은 클로드가 스킬을 구분하려고 쓰는 것입니다.
  평소 쓰는 말로 하면 됩니다.
- 엉뚱하게 안 불리면 `민원-월간갱신 스킬로 갱신해줘`처럼 이름을 대면 됩니다.
  **이렇게 해야만 불린다면 본문이 아니라 `description`을 고쳐야 한다는 신호입니다.**
- 매달 잊지 않으려면 한 번만 말해 둡니다 —
  `매월 1일 오전 9시에 민원 월간 갱신을 실행해줘.`

## 규칙은 여기 없습니다

원본 보존·마스킹·추정 표시 같은 규칙은 `CLAUDE.md`에 있습니다. SKILL.md에 다시 쓰지
않았습니다. 두 곳에 같은 규칙이 있으면 한쪽만 고쳤을 때 어느 쪽이 맞는지 알 수 없습니다.
