# 연습 과제 — 실습 입력

중급에서 쓴 프롬프트를 **그대로** 새 폴더에 돌려 봅니다. 새올구는 다른 동네입니다.

## 작업 폴더는 직접 만듭니다

이 폴더에 있는 것이 **입력 전부**입니다. 작업 폴더는 학습자가 만듭니다.

1. 빈 폴더를 하나 만듭니다.
2. `CLAUDE.md`를 그 폴더 **루트**에 넣습니다. Claude Code가 매 명령마다 읽습니다.
3. `input/`을 통째로 복사합니다. **input 안의 파일은 수정하지 않습니다.**
4. `working/`과 `output/` 빈 폴더를 만듭니다.

```
내작업폴더/
  CLAUDE.md     상시 규칙
  input/        원본 — 읽기 전용
  working/      판단의 흔적 (계획 · 변경 로그 · 검토 기록)
  output/       산출물 (보고서 · 지도 · 대시보드)
```

## 붙여넣기를 줄이고 싶다면 — 스킬 (선택)

프롬프트 A–L을 이번에도 열두 번 붙여넣게 됩니다. 같은 절차를 다음 달에도 쓸
것이라면 **스킬**로 만들어 두면 붙여넣지 않아도 됩니다. 중급 교안의
「규칙은 CLAUDE.md에, 절차는 스킬에」 장에서 다룬 것입니다.

- **CLAUDE.md** — 매 명령마다 읽힙니다. 안 변하는 규칙을 둡니다.
- **스킬** — 그 일을 할 때만 꺼내집니다. 반복되는 절차를 둡니다.

만드는 곳은 둘 중 편한 쪽입니다.

| 쓰는 도구 | 두는 곳 |
|---|---|
| Claude Code · Claude Desktop | 작업 폴더 안에 `.claude/skills/<이름>/SKILL.md` |
| claude.ai (웹) | `Settings → Capabilities`에서 **코드 실행**을 켠 뒤, `Customize → Skills`에 스킬 폴더를 ZIP으로 올립니다 |

SKILL.md는 맨 위 두 줄만 지키면 됩니다.

```markdown
---
name: 민원-품질검사
description: 민원 CSV의 중복·결측·이상치를 점검하고
  working/cleaning_log.md에 건수와 이유를 남긴다
---

① input/ 원본은 열기만 한다
② 중복·결측·범위 이탈을 각각 센다
③ 건수·행번호·이유를 로그에 남긴다
④ 사람 확인을 기다린다
```

**`name`과 `description`만이 발동을 결정합니다.** 아래 절차 본문은 발동에
영향을 주지 않습니다. 그래서 "언제 이것을 꺼내야 하는가"를 description에
쓰는 것이 전부입니다. 직접 쓰기 어려우면 Claude에게 `skill-creator`로
만들어 달라고 하면 됩니다 — 되묻는 질문에 답하면 만들어 줍니다.

이 과제는 스킬 없이도 완주할 수 있습니다. 붙여넣기가 번거로울 때 쓰십시오.

## input 파일

| 파일 | 내용 | 규모 |
|---|---|---|
| `complaints_200.csv` | 무단투기 민원 원본 (오염·개인정보 포함) | 212행 × 16열 |
| `cctv_existing_30.csv` | 기존 CCTV — 설치연도·화소·촬영방향·야간성능 | 30행 × 10열 |
| `district_profile.csv` | 행정동 현황 — 인구·세대·상가·원룸비율·분리수거함 | 7행 × 12열 |
| `project_conditions.txt` | 사업조건 — 예산 3천만원 · 단가 9종 · 제약 6개 | 텍스트 |

**정답 수치는 공개하지 않습니다.** 스스로 세고 검산하는 것이 이 과제의 목적입니다.
어제 본 숫자를 그대로 옮겨 적으면 전부 틀립니다.

## 이 폴더에 없는 것

완성본 웹앱과 정답키는 들어 있지 않습니다.
**교안의 프롬프트로 직접 만드는 것이 과제입니다.**

데이터는 전부 교육용 가상(합성) 자료입니다.
