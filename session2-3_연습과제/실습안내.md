# 연습 과제 — 실습 입력

중급에서 쓴 프롬프트를 **그대로** 새 폴더에 돌려 봅니다. 새올구는 다른 동네입니다.

## 작업 폴더는 직접 만듭니다

이 폴더에 있는 것이 **입력 전부**입니다. 작업 폴더는 학습자가 만듭니다.

1. 빈 폴더를 하나 만듭니다.
2. `CLAUDE.md`를 그 폴더 **루트**에 넣습니다. Claude Code가 매 명령마다 읽습니다.
3. `input/`을 통째로 복사합니다. **input 안의 파일은 수정하지 않습니다.**
4. `working/`과 `output/` 빈 폴더를 만듭니다.

```
내작업폴더/
  CLAUDE.md     상시 규칙
  input/        원본 — 읽기 전용
  working/      판단의 흔적 (계획 · 변경 로그 · 검토 기록)
  output/       산출물 (보고서 · 지도 · 대시보드)
```

## input 파일

| 파일 | 내용 | 규모 |
|---|---|---|
| `complaints_200.csv` | 무단투기 민원 원본 (오염·개인정보 포함) | 212행 × 16열 |
| `cctv_existing_30.csv` | 기존 CCTV — 설치연도·화소·촬영방향·야간성능 | 30행 × 10열 |
| `district_profile.csv` | 행정동 현황 — 인구·세대·상가·원룸비율·분리수거함 | 7행 × 12열 |
| `project_conditions.txt` | 사업조건 — 예산 3천만원 · 단가 9종 · 제약 6개 | 텍스트 |

**정답 수치는 공개하지 않습니다.** 스스로 세고 검산하는 것이 이 과제의 목적입니다.
어제 본 숫자를 그대로 옮겨 적으면 전부 틀립니다.

## 이 폴더에 없는 것

완성본 웹앱과 정답키는 들어 있지 않습니다.
**교안의 프롬프트로 직접 만드는 것이 과제입니다.**

데이터는 전부 교육용 가상(합성) 자료입니다.
